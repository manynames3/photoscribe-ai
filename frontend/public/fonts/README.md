# Typography Assets

Source Sans 3 (regular and semibold) and Source Serif 4 (regular) are self-hosted
to keep the landing page and staff interface consistent across devices without
third-party font requests. Original assets came from Google Fonts' official
font service and were losslessly converted to WOFF2 with FontTools. Glyphs and
embedded font names are unchanged.

- [Source Sans 3](https://github.com/adobe-fonts/source-sans): `source-sans-LICENSE.txt`.
- [Source Serif 4](https://github.com/adobe-fonts/source-serif): `source-serif-LICENSE.txt`.

Both are distributed under the SIL Open Font License. CSS aliases are used only
for the application's shared typography tokens. The conversion tools are not
application dependencies.
